# LLM Engineering Playbook · 大模型应用工程：方法边界与选型手册

> 这不是学习笔记，是一本**工程决策手册（Engineering Playbook）**。

## 这个仓库是什么

记录的不是"我学了什么"，而是**"遇到什么问题 → 选什么方案 → 边界在哪 → 为什么"**。

大模型应用工程的方法论文章很多，但绝大多数在讲"怎么做"，很少讲"**什么时候不该做**"。工程实践里真正贵的知识是边界：哪些问题用纯 API 调用就能解决，哪些必须上系统层，哪些才轮到微调——把选错路线的成本提前标出来，是本仓库的唯一目的。

## 适合谁读

- 我自己：跨项目复用的判断依据，避免每次重新推导。
- 学生 / 团队新成员：**onboarding 文档**。读完这一篇，就知道拿到一个"让模型稳定输出"的需求时，第一步做什么、第四步才做什么、什么情况下该停。
