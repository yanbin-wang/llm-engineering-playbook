## Prompt Tuning 怎么做（机制，理解边界即可）

- **冻结全部模型权重**，只训练一组**连续向量**（soft prompt）：在输入层（Prefix Tuning 则在每层 Transformer 前）拼接可训练向量，与文字 prompt 一起送入模型。
- 训练数据就是（输入 → 期望输出）对，梯度反传只更新这些向量，模型本体不动。
- 产物是**一组数值向量**，不是文字：人读不了、改不了，也基本不能跨模型迁移。
- 前提：必须能访问模型内部计算（自部署开源模型）。在线 API 给不了这个入口——这就是它在工程实践里出场率远低于 Prompt Design 的原因。

## 提示注入（安全项）

- **提示注入**（Prompt Injection）：安全对抗概念，攻击者嵌入恶意指令劫持模型行为，部署时需防范
